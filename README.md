# LOG 行動工作台

手機優先、可安裝、資料在本機的 PWA。這是第一版互動與規則試排，不是 2027-10 的正式替代品。

## 使用

1. 從「資料」匯入 XLSX，選工作頁、起始列、筆數和廠別；一般預設 B→D、C→E，油類依廠別反轉。可另外反轉本次來源。原始字串不補字、不截短。檔名未辨識廠別時必須選擇，不沿用上一張卡夾；匯入前可看設備、樓層、型式、區域與小組預覽。
   工作頁使用完整名稱選取，保留中文字、半形／全形括號與空白；搜尋可對應全半形括號。隱藏及深度隱藏頁預設收起，勾選「顯示隱藏工作頁」後會附註狀態；不改來源檔的可見性。讀取只解析所選頁及指定列，切頁時過期的讀取結果不會套入新頁。
2. 匯入後預設顯示連續表格，全部 400 筆可直接捲動；設備原碼 E 是第一個主欄，元件 D 與設備、樓層、型式等欄位可橫向查看。也可切回卡片，兩個原始碼都會直接顯示。
3. 「標記」可篩選黃底、紅底、藍底、樓層紅字或加時黃字；「保留前後 1 筆」用來對照邊界，鄰近參照列不會被「選全部篩選」自動選入。先選筆數，再展開上色工具；清除選取後工具自動收起。最多保留 12 步復原，樓層紅字會補黃底，既有紅底保留。
4. 「設定」分上午、下午、一般／難、Auto／廠外、進場／收尾、跨區與遠距組合。時刻可填 0820 或 13:06；期間改用分秒：`2.22`／`222`／`2:22` 都是2分22秒；1～2位整數為分鐘，3～4位整數為MMSS，點後一位為秒（`2.2`＝2分2秒），不再當小數分鐘。使用原生鍵盤。
5. 遠距組合設定共用上下限，可再覆寫單筆；每筆只套一個組合。修改資料、標記、遠距或時間後，舊結果會失效。
6. 試排在 Web Worker 中執行，可取消；20 秒到期會終止本次工作程序，不把有限搜尋失敗宣稱無解。點元件查看原文、解析、時間與間隔規則。
7. 自動保存卡夾於 IndexedDB；匯出 `.log.json` 可換裝置，匯入後不信任舊計算結果，必須重算。CSV 明確為試排資料，不是 1000／2020 的 TXT。
8. 結果的「80窗（分）」對應 Excel LOG!G：從本筆往後80間隔（81個時間點），整數分鐘顯示在起筆。核對來源：`2027-10LOG.xlsm` 的 `xl/worksheets/sheet4.xml` G5/G6，核心 `INT(ROUND((H[row+80]-H[row])*86400,0)/60)`。61以上通過，60及以下不通過；跨午休／往後不足81筆顯示「—」。上午、下午最低值與逐筆值使用相同完整結果計算，篩選不重算窗口。廠外保留數字但不套80門檻。
9. 「本段筆數」顯示當筆位置／全段總數（例如4／23）；黃、紅、藍底均從1重起，到下一底色的前一筆結束。全段超過29筆就標紅；未有段首不假造數值。卡片將時間、背景計數、80窗分成三欄，設備名稱用紅字粗體。
10. 卡片捲到底會自動續載；設備名稱與完整來源上一筆不同時提醒「換設備」，無底色時另提醒。結果頁固定列出所有筆數，可切換長短編碼；未排或過期結果的時間及 G 留空。間隔達1:31使用獨立提示色，保留原背景與字色。型式含C／P／R／S／A／I任一字母時以粉色及+1:00標示，和試排共用同一判定；每筆只額外加60秒一次，不依設備名稱誤判。
11. 新空白畫面不預設ARO1；未編輯、未匯入的空白佔位不會自動存成卡夾。刪除末張後保持空白，切到背景不會把已刪卡夾存回。舊卡夾不批次刪除。
12. 從「資訊」或「時間設定」開啟獨立「操作說明」頁，只列顏色與時間。範圍跟著本卡夾設定；樓層表可展開查看相差1～27層的上／下樓加背景時間，首筆例外與黃字不重複疊加也會列明。

13. 下午首筆使用正式黃底（既有紅底保留），本段筆數重新由1開始；只修正底色，不另外疊加背景秒數。標記、結果與A/B讀取同一背景；重新試排不把舊下午切點永久留在來源標記。
14. 「背景/值」獨立分頁只列設備長碼、A背景、B淨檢、型式。完成有效時間後可生成，預設A 0.8～2.7、B 0.8～4.9；1000兩位、2020一位小數。A按實際底色分段共用，B每筆獨立；兩者生成序列都避開相鄰及隔一筆重複。人工修改A同步整段，B只改單筆；人工數值不強行截小數。範圍修改不改現值，生成才套用。
15. 背景分段變動時清除過期A/B並提示，可復原；人工改A/B不使時間失效。卡夾保存A/B及範圍，CSV附A/B；手動刪除時間未納入自動排程。

16. 主分頁依序為資料、標記、時間設定、廠別規則、匯入參數、背景/值、結果。廠別規則與匯入參數這輪只預留主分頁，尚無可改參數。結果是全寬最終確認頁；表格限制於可上下、左右滑動的視窗，表頭、筆號與設備長／短碼固定。所有400筆仍在同一張表內，保留底色、字色、A/B、型式、G、時間、間隔、背景段、設備與樓層。

17. 手動時間採分階段編排：先設定基礎、Rand和上午候選時段，僅生成上午。多選、連選或按元件編號選段後批次刪除時刻；元件不刪除，剩餘保留時刻依原順序對應元件。左側#永遠是元件編號，已刪時刻與備用顯示—。G按保留元件即時核算。可還原選取或復原最近20步。
18. 上午編排完成後，點選最後元件並按「上午到第N筆結束」，或用上方確認目前末筆。確認後才將其餘元件留給下午；下午由使用者另行指定基礎、Rand及時段，按「生成下午」。下午生成不重抽上午。上午確認後鎖定；要修改須明確「重開上午」，保留上午時刻並清除下午候選，可復原。舊schema1/2/3候選保持原時刻與切點，按「改用上午確認切點」才轉新流程。schema4卡夾保存階段、切點及獨立下午亂數。

19. 手動大表顯示時間／間隔、G分、規則差額、樓層、型式、設備與完整碼；刪除、還原與改間隔即時計算G。選取框不重複顯示原秒與G，分塊顯示目前間隔、規則差額、刪除後間隔與差額。展開「修改間隔」可填分秒：1.34／134／1:34均為94秒，1～2位整數為分鐘。該筆及同半日後續時刻移動相同差值，前段與另一半日不變，不自動全段重配。下午修改若使完整元件不足以放入截止前，會拒絕且保留原值。編排上午時超過截止的候選不再映射，剩餘元件留待下午。刪除提示固定於行內，不擋操作。
20. 上午確認且下午候選完成後，「自動調整預覽」以獨立Worker固定筆數、來源順序、標記與午休切點，依逐列上下限、80窗與收尾重新分配整數秒數。成功須通過原驗證器；採用回填後再次核對，最後「套用至結果」。失敗、取消或20秒到期不改候選。有界搜尋失敗不代表數學無解。手動亂數公式與Excel ROUND(RAND()*差值+基礎,0)相同；普通亂數本身不補規則秒數，也不把元件數鎖成240/160。

21. 廠別解析補上FAS、大連、南北儲、中油、油料二、基礎油、油品部成品課及南儲，與原有9廠分別判定；油類保留來源方向、括號及長短區碼對照，樓層別名採原表（含4.5→4）。INA／PVC／手動、精確人工例外及目前尚不支援的可靠空小組明確提示，不預設通過。舊卡夾可按「重新判定待確認」，只更新有解析問題的筆、保留已人工修正內容；原碼／標記保留，可復原，解析變更後時間須重算。

22. 結果頁直接提供「產出TXT」、「上傳暫存」及「鑰匙取件」。時間、背景或A/B未通過時開啟明確缺項視窗，提供前往修改的按鈕，絕不輸出不合格檔案。通過後檢查檔頭並預覽1000／2020格式（UTF-8無BOM、CRLF、每筆110字）。下載使用真正的Blob檔案連結，可點擊或長按；瀏覽器支援時另外提供系統「分享／存到檔案」。上傳仍需預覽後另按加密上傳；資料不會自動傳送。日期、份數、廠區、人員、儀器、D／E來源與二校均嚴格檢查。

23. 「加密上傳」是另一個明確按鈕，沒有按下就不傳送。裝置先以隨機256-bit鑰匙及AES-GCM加密檔名和完整TXT，Worker只收到密文、IV及鑰匙SHA-256所成的ID；唯一解密鑰匙只留在本機與使用者複製的內容，不送到伺服器。期限從第一次成功上傳時起算12小時；相同ID重送相同內容只回原收據，不延長期限。若上傳後未取得明確成功收據，畫面保留待確認鑰匙；任何重新嘗試前都應先用該鑰匙取件確認，避免盲目重送。

## 範圍與限制

- 正式 Excel 工作簿、C++ 及 StrForge 未變更。
- 公開專案只放程式、規則與合成示範，不放工廠 XLSX、TXT 或使用者元件。
- 讀取XLSX不執行VBA，卡夾與本機TXT不會自動上傳，也不需要API金鑰；只有使用者明確按「加密上傳」才傳送當次密文包。
- 已移植規則及未完成項目見 `DOMAIN.md`。尚未證明與 -10 全廠解析／求解等價；不可把手機試排當成原生 Excel 驗收。
- 已提供本機1000／2020 TXT固定格式輸出；-10候選池、同條件重生保優和C++整理仍未移植。這不表示各廠資料皆已通過原生Excel逐檔驗收。
- 加密傳輸的HTTP JSON包上限為512 KiB，包含base64、JSON及AES-GCM額外資料，因此可傳的原始TXT會較小。暫存後端使用Cloudflare KV binding `LOG_TXT`；`LOG_RATE` 部署設定為每個來源30次／60秒時才啟用限流。CORS正式來源固定為 `https://yang-00712.github.io`；CORS與限流都不是身份驗證。
- TXT服務已部署至 `https://log-txt.cat980411.workers.dev`，`LOG_TXT` 與 `LOG_RATE` 已綁定。已用合成文字實測加密上傳、取回後bytes相同、重送不續期及不允許來源403；實體iPhone操作與各廠原生Excel逐檔驗收尚未完成。
- 首次連線後才有離線資源；清除網站資料可能失去卡夾，請匯出備份。手機切至背景可能暫停 Worker，回前景後可取消再試；不承諾背景持續運算。
- XLSX 檔案最多 20 MB、解壓宣告總量 160 MB、每份 448 筆。大型活頁簿在獨立 Worker 讀取，匯入或關閉後釋放。

## 本機與發布

Node 22 或更新：`npm test`；`npm start` → `http://127.0.0.1:4173`。

GitHub Pages：`Settings → Pages → Deploy from a branch → main → /(root)`。所有資源採相對路徑，適用 `https://yang-00712.github.io/-/`，無需建置或伺服器。

版本由 `version.js` 的 `LOG_RELEASE` 統一管理（本次 `r20`）；Service Worker 快取名稱和資訊視窗都讀同一來源。每次部署程式改動時更新此版本，無須再手改另一個CACHE編號。版本檢查用帶 `_logcheck` 的網路請求及 `no-store`，不從離線殼讀取線上版本。開啟及回到前景時自動檢查，閒置時先保存卡夾再更新；開始操作後只提示。手動按一次即可接續下載、保存與套用，iOS不依按鈕焦點判定回饋。資訊內列出目前／線上版本及狀態；更新前記錄目標版本，新頁載入後確認相符才清除標記。版本不符、檢查超時或重新載入未完成會提供可重試狀態，不無限自動重載。多分頁、計算／匯入、開啟編輯器、保存失敗仍會阻擋；資訊視窗不算編輯器。更新不清除卡夾；手機主畫面圖示的快取與程式版本分開判斷。

## 維護

- `app.mjs`／`app.css`：手機與桌面 UI、選取、遠距、卡夾。
- `plant-parser.mjs`：各廠分流、來源方向、區碼與樓層別名、保守解析及支援狀態。
- `storage.mjs`：儲存、匯入資料驗證與輸出；`domain.mjs`：純規則核心；`validation.mjs`：完整結果的80間隔顯示核算。
- `version.js`：唯一發布版本來源；`update.mjs`／`sw.js`：線上與已載入版本核對、保存後更新及離線資源管理。
- `manual-time.mjs`／`manual-ui.mjs`／`manual-preview.mjs`：手動候選核心、批次選取與套用頁；`domain.mjs` 的 `inspectManualSchedule` 只驗證手動結果，不改時刻。
- `manual-adjust.mjs`／`manual-adjust-worker.mjs`：使用者明確啟動的有界整數時間修正、提案與獨立驗算；不在一般刪除時執行。
- `measurements.mjs`：A/B生成與分段編輯；`job-rows.mjs`：當次排程底色與A/B過期防護。
- `txt-export.mjs`／`txt-output-ui.mjs`：1000／2020固定寬度TXT組裝、本機下載、加密上傳與鑰匙取件流程；`txt-transfer.mjs`：AES-GCM客戶端加解密、收據核對、逾時及大小限制。
- `cloudflare/worker.mjs`：只保存密文包的12小時 `LOG_TXT` KV介面；可選 `LOG_RATE` binding存在時才執行限流。Worker不接收解密鑰匙。
- `import-worker.js`：SheetJS 匯入；`solver-worker.mjs`：試排 Worker。
- `tests/`：純核心與狀態驗證；瀏覽器實際操作仍需另做。
- `vendor/xlsx.mini.min.js`：SheetJS CE 0.20.3 官方 mini build，Apache-2.0，詳見 `vendor/LICENSE`。

本專案不自動同步卡夾到GitHub；只有使用者選擇跨裝置取件時，才把當次AES-GCM密文暫存到Cloudflare KV。
