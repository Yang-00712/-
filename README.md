# LOG 行動工作台

手機優先、可安裝、資料在本機的 PWA。這是第一版互動與規則試排，不是 2027-10 的正式替代品。

## 使用

1. 從「資料」匯入 XLSX，選工作頁、起始列、筆數和廠別；一般預設 B→D、C→E，油類依廠別反轉。可另外反轉本次來源。原始字串不補字、不截短。
   工作頁使用完整名稱選取，保留中文字、半形／全形括號與空白；搜尋可對應全半形括號。隱藏及深度隱藏頁預設收起，勾選「顯示隱藏工作頁」後會附註狀態；不改來源檔的可見性。讀取只解析所選頁及指定列，切頁時過期的讀取結果不會套入新頁。
2. 匯入後預設顯示連續表格，全部 400 筆可直接捲動；設備原碼 E 是第一個主欄，元件 D 與設備、樓層、型式等欄位可橫向查看。也可切回卡片，兩個原始碼都會直接顯示。
3. 「標記」可篩選黃底、紅底、藍底、樓層紅字或加時黃字；「保留前後 1 筆」用來對照邊界，鄰近參照列不會被「選全部篩選」自動選入。先選筆數，再展開上色工具；清除選取後工具自動收起。最多保留 12 步復原，樓層紅字會補黃底，既有紅底保留。
4. 「設定」分上午、下午、一般／難、Auto／廠外、進場／收尾、跨區與遠距組合。時刻可填 0820 或 13:06；期間改用分秒：`2.22`／`222`／`2:22` 都是2分22秒；1～2位整數為分鐘，3～4位整數為MMSS，點後一位為秒（`2.2`＝2分2秒），不再當小數分鐘。使用原生鍵盤。
5. 遠距組合設定共用上下限，可再覆寫單筆；每筆只套一個組合。修改資料、標記、遠距或時間後，舊結果會失效。
6. 試排在 Web Worker 中執行，可取消；20 秒到期會終止本次工作程序，不把有限搜尋失敗宣稱無解。點元件查看原文、解析、時間與間隔規則。
7. 自動保存卡夾於 IndexedDB；匯出 `.log.json` 可換裝置，匯入後不信任舊計算結果，必須重算。CSV 明確為試排資料，不是 1000／2020 的 TXT。
8. 結果的「80窗（分）」對應 Excel LOG!G：從本筆往後80間隔（81個時間點），整數分鐘顯示在起筆。核對來源：`2027-10LOG.xlsm` 的 `xl/worksheets/sheet4.xml` G5/G6，核心 `INT(ROUND((H[row+80]-H[row])*86400,0)/60)`。61以上通過，60及以下不通過；跨午休／往後不足81筆顯示「—」。上午、下午最低值與逐筆值使用相同完整結果計算，篩選不重算窗口。廠外保留數字但不套80門檻。
9. 「本段筆數」顯示當筆位置／全段總數（例如4／23）；黃、紅、藍底均從1重起，到下一底色的前一筆結束。全段超過29筆就標紅；未有段首不假造數值。卡片將時間、背景計數、80窗分成三欄，設備名稱用紅字粗體。
10. 新空白畫面不預設ARO1；未編輯、未匯入的空白佔位不會自動存成卡夾。刪除末張後保持空白，切到背景不會把已刪卡夾存回。舊卡夾不批次刪除。

## 範圍與限制

- 正式 Excel 工作簿、C++ 及 StrForge 未變更。
- 公開專案只放程式、規則與合成示範，不放工廠 XLSX、TXT 或使用者元件。
- 讀取檔案不執行 VBA，不上傳伺服器，不需要 API 金鑰。
- 已移植規則及未完成項目見 `DOMAIN.md`。尚未證明與 -10 全廠解析／求解等價；不可把手機試排當成原生 Excel 驗收。
- 尚未提供正式 A/B 數值生成、1000／2020 TXT 位元組精準輸出，以及 -10 候選池、同條件重生保優和 C++ 整理。
- 首次連線後才有離線資源；清除網站資料可能失去卡夾，請匯出備份。手機切至背景可能暫停 Worker，回前景後可取消再試；不承諾背景持續運算。
- XLSX 檔案最多 20 MB、解壓宣告總量 160 MB、每份 448 筆。大型活頁簿在獨立 Worker 讀取，匯入或關閉後釋放。

## 本機與發布

Node 22 或更新：`npm test`；`npm start` → `http://127.0.0.1:4173`。

GitHub Pages：`Settings → Pages → Deploy from a branch → main → /(root)`。所有資源採相對路徑，適用 `https://yang-00712.github.io/-/`，無需建置或伺服器。

更新程式時一併更新 `sw.js` 的 CACHE 名稱，避免混用新舊模組。開啟及回到前景時會檢查版本，亦可手動按「更新」檢查。待新版所有離線資源備齊才可套用，按下後先保存卡夾再重新載入；保存失敗、編輯視窗未關閉、計算／匯入中都不更新。另有其他LOG分頁時會要求先關閉，避免混用模組。更新不清除卡夾；手機主畫面圖示由作業系統快取，可能需重新加入捷徑才換圖。

## 維護

- `app.mjs`／`app.css`：手機與桌面 UI、選取、遠距、卡夾。
- `storage.mjs`：儲存、匯入資料驗證與輸出；`domain.mjs`：純規則核心；`validation.mjs`：完整結果的80間隔顯示核算。
- `update.mjs`／`sw.js`：檢查新版、保存後更新與離線資源管理。
- `import-worker.js`：SheetJS 匯入；`solver-worker.mjs`：試排 Worker。
- `tests/`：純核心與狀態驗證；瀏覽器實際操作仍需另做。
- `vendor/xlsx.mini.min.js`：SheetJS CE 0.20.3 官方 mini build，Apache-2.0，詳見 `vendor/LICENSE`。

本專案不需要雲端資料庫，也不自動同步卡夾到 GitHub。
